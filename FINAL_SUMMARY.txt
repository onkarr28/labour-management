## 💡 KEY CALCULATIONS

### Financial Formulas
```
Earned Amount = Present Days × Daily Rate

Net Payable = Earned Amount - Total Advances

Attendance % = (Present Days / Working Days) × 100

Advance Ratio = (Total Advances / Earned Amount) × 100

Weekly Payout = Σ(Worker Weekly Net Pay)
```

## 📱 USER WORKFLOWS

### Adding a Worker
```
1. Tap "Add New Labour"
2. Fill form (name, mobile, rate, trade)
3. Submit → Worker added
```

### Marking Attendance
```
1. Go to Workers → Select worker
2. Tap "Mark Attendance"
3. Calendar opens
4. Tap date to mark Present/Absent
5. Long-press to add advance
```

### Viewing Reports
```
1. Go to Reports tab
2. See weekly statistics
3. Worker breakdown table
4. Payday checklist
```

## 🔒 DATA STORAGE

### AsyncStorage Keys
```javascript
'@labours'              // All worker objects
'@contractor_profile'   // Contractor details
'@app_settings'         // App preferences
'@payment_history'      // Payment records
```

### Worker Data Schema
```javascript
{
  id: 'unique-id',
  name: 'Worker Name',
  mobile: '10digits',
  dailyRate: 600,
  trade: 'Mason',
  joiningDate: 'YYYY-MM-DD',
  attendance: { 'YYYY-MM-DD': { status, marked } },
  advances: [{ date, amount, note }],
  totalAdvance: number,
  currentBalance: number,
  photo: 'uri-or-null'
}
```
