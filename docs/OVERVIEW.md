# Labour Management System - Documentation

## Project Overview

This is a comprehensive labour management system designed to streamline workforce operations.

## Modules

1. **Employee Management** - Add, update, and manage employee records
2. **Attendance System** - Track daily attendance and working hours
3. **Leave Management** - Manage employee leave requests and approvals
4. **Payroll** - Calculate salaries and generate payslips
5. **Reports** - Generate various HR and attendance reports
