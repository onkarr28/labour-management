Firebase Storage Rules - IMPORTANT!
=====================================

Go to Firebase Console:
https://console.firebase.google.com/project/labour-management-e3795/storage/

Click on "Rules" tab and replace with these rules:

```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    // Allow anyone to read photos (publicly accessible)
    match /{allPaths=**} {
      allow read: if true;
    }
    
    // Allow authenticated writes to worker-photos folder
    match /worker-photos/{fileName} {
      allow write: if true;  // For development - allows all uploads
      allow delete: if true;
    }
  }
}
```

After setting these rules, click "Publish" to apply them.

IMPORTANT: These rules allow public write access for development.
For production, you should restrict based on authentication.

Production rules (after implementing Firebase Auth):
```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read: if true;
    }
    
    match /worker-photos/{fileName} {
      allow write: if request.auth != null;
      allow delete: if request.auth != null;
    }
  }
}
```
