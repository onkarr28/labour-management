## Features

### For Contractors:
1. ✅ **Auto-refresh dashboard every 1 second** - Live updates of worker attendance and financial data
2. ✅ **Separate contractor accounts** - Each contractor has their own login credentials
3. ✅ **Worker filtering** - Each contractor only sees their own workers
4. ✅ **Financial tracking** - Advances and payments are tracked separately per contractor
5. ✅ **Account settlement** - Clear hisaab (accounts) after payments

### For Workers:
1. ✅ **Worker login** - Each worker has their own login credentials
2. ✅ **View personal data** - Attendance, salary, advances, and payments
3. ✅ **Worked sites history** - Track all sites where work was completed

## Notes

- Each contractor's dashboard auto-refreshes every second
- Workers only see their own contractor's data
- Advances and payments are tracked independently per contractor
- Login credentials are case-sensitive
